FUNKY MAKER
PLAYER

Un reproductor de niveles de Funky Maker para Windows.

Arrastra un archivo .FNMM o .rar a la ventana para cargar un nivel
Descargar Volver al Lab

✦ Características

📦
Carga de niveles
Soporta archivos .FNMM (ZIP y RAR) con drag & drop directo.
🎸
Múltiples strumlines
Soporte completo para niveles con múltiples strumlines simultáneas.
▶️
Autoplay y manual
Alterna entre modo automático y control manual en cualquier momento.
⬇️
Downscroll
Modo downscroll disponible para los que prefieren las notas bajando.
⏱️
Timer estilo Psych
Timer de canción con el estilo visual de Psych Engine.
⏩
Timeskip
Salta hacia adelante o atrás en la canción con Tab / Shift+Tab.
❤️
Barra de vida
Colores de la barra de vida basados en el icono del personaje.
⚙️
Settings persistentes
Tu configuración se guarda automáticamente entre sesiones.
💀
Notas especiales
Soporte para notas de daño, instakill y heal.
🎮
Compatibilidad Psych
Compatible con niveles creados para Psych Engine.

✦ Controles

Tecla Acción
↑ ↓ ← → / WASD Notas (configurable)
ESC Pausa / Settings
P Pausar
Tab Timeskip +Xs
Shift + Tab Timeskip -Xs
F11 Fullscreen
+ / - Velocidad de scroll
