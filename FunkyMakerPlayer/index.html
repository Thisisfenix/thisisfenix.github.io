✦ Características

🎮 Reproducción ▼
Carga de Niveles
Arrastra y suelta archivos .FNMM o .rar. Importación automática.
Múltiples Strumlines
Soporte para niveles con varias pistas simultáneas.
Autoplay
Modo automático para previsualización de niveles.
Seek / Skip
Navega a cualquier punto con Tab/Shift+Tab.
Eventos
Soporte para eventos: cámara, zooms y efectos especiales.
Notas Especiales
Soporte para notas de daño, instakill y curación.
⚡ Gameplay ▼
Midlescroll / Downscroll
Centra las notas o invierte su dirección.
Sistema de Scoring
Evaluación precisa con accuracy y ratings.
Opciones de Gameplay
Ghost tapping, buffer, safe frames y scroll speed ajustables.
Rebinding
Personaliza los controles a tu gusto.
Temporizador
Progreso y tiempo restante. 7 esquemas de color.
Healthbar
Colores extraídos de los iconos de personajes.
🎨 Personalización ▼
Noteskins y Splashes
Soporta skins de notas y efectos personalizados.
Color Grading
Filtros de color: hue, saturación, brillo y sombras.
Visibilidad UI
Oculta strumlines, combo y otros elementos.
Configuración
Panel completo: Gameplay, Visuales, Audio, Debug.
⚙️ Sistema ▼
Windows y Linux
Nativo para ambos sistemas. Script de auto-instalación en Linux.
Optimizado
Ejecutable autónomo. Sin dependencias ni instalación.
Persistencia
Guarda configuración y progreso automáticamente.
Multiidioma
Español 🇪🇸, Inglés 🇬🇧 y Portugués 🇧🇷.
Privacidad
Sin telemetría. Todo local.
Formatos
.FNMM, .rar, .zip y recursos de la comunidad.

✦ Notas

En desarrollo — Pueden aparecer bugs o comportamientos inesperados. Reporta problemas en GitHub o contacta a @thisisankush en Discord.
FunkyMakerPlayer es un reproductor de escritorio no oficial para niveles de Funky Maker: Mobile!, desarrollado con fines educativos y de entretenimiento. Todo el crédito del juego original pertenece a KinGamesCreator. Este proyecto no está afiliado, patrocinado ni respaldado oficialmente. Si tienes algún problema con este proyecto, contacta a @thisisfenix.
Compatibilidad
Este reproductor soporta niveles en formato .FNMM y .rar/.zip creados con Funky Maker: Mobile! Algunas características avanzadas o mods de la comunidad pueden no ser totalmente compatibles.
