Descomprime la carpeta, mete tus niveles (.fnmm, .zip o .rar) en mods/levels/ o arrástralos ya dentro del juego. Si Windows muestra el aviso de SmartScreen, dale a Más información → Ejecutar de todas formas.

Requisitos

  • Windows: Windows 10 / 11 (64-bit). El ejecutable ya trae el runtime de .NET 10.
  • Linux: x64 (Ubuntu, Fedora, Arch, etc.) con OpenGL 3.3+. Ejecuta chmod +x run.sh && ./run.sh.
  • Android: Android 10 (API 29) o superior, con controles táctiles incluidos.
  • Espacio: ~150–300 MB libres entre el juego y caché de niveles.

Bugs e issues: Todavía tiene bugs y cosas a medias. El código oficial está abierto en GitHub Issues por si quieres reportar algo o mandar un PR, o me puedes escribir a @thisisankush en Discord.

Disclaimer: Proyecto hecho por fans, gratis y sin afiliación oficial con KinGamesCreator. Todo el mérito del juego original es suyo.
